🧠 Deep Learning Architecture

FloraScan AI leverages MobileNetV2, an efficient convolutional neural network pre-trained on ImageNet (1.4 million images across 1,000 categories). MobileNetV2 uses inverted residual blocks and depthwise separable convolutions to drastically reduce parameter count and compute complexity while preserving high representational capacity.

  • Backbone: MobileNetV2 pre-trained weights (feature extractor producing 1,280-dimensional embeddings)
  • Custom Classification Head: Dropout(0.25) → Linear(1280, 512) → ReLU → Dropout(0.20) → Linear(512, N_classes)
  • Loss Function: Cross-Entropy Loss with Softmax activation
  • Optimizer: AdamW (Learning rate: 3e-4, Weight decay: 1e-4) with Cosine Annealing learning rate schedule

🔌 RESTful API Documentation

Integrate automated leaf disease detection into mobile applications, drones, or automated greenhouse systems via standard HTTP requests.

1. Detect Disease via Multipart Form File

curl -X POST http://127.0.0.1:5000/api/predict \ -F "image=@/path/to/leaf_photo.jpg"

2. Detect Disease via Base64 JSON

curl -X POST http://127.0.0.1:5000/api/predict \ -H "Content-Type: application/json" \ -d '{"image_base64": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQ..."}'
