# Week 2 — Handwritten Digit Classifier

This folder contains the MNIST handwritten-digit classifier notebook.

## Run
1. Open `Week2_Assignment.ipynb` in VS Code or Jupyter Notebook.
2. Install packages:
   ```bash
   pip install tensorflow numpy matplotlib scikit-learn
   ```
3. Run all cells from top to bottom. An internet connection may be needed the first time to download MNIST.

## Notebook output
- Sample MNIST image and sample predictions
- Neural network training and test loss/accuracy
- Accuracy, macro precision, and macro recall
- Confusion matrix
- Five incorrect predictions and short error analysis
- Training/validation accuracy and loss plots
