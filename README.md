# Deep Learning AI Internship — Week 1

## Folder guide
- `Week1/assignment/Week1.ipynb`: Assignment 1 covering concepts, tensor operations, synthetic regression, loss plots, and learning-rate comparison.
- `Week1/Mini-project/`: MNIST handwritten digit recognizer website.

## Assignment setup
Install the assignment dependencies: `pip install torch matplotlib jupyter`
Open `Week1/assignment/Week1.ipynb` in Jupyter Notebook or VS Code and run cells from top to bottom.

## MNIST mini-project setup
Open `Week1/Mini-project/README.md` and follow its setup instructions. The trained model file is included in this ZIP.
