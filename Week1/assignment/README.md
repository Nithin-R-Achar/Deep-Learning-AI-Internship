# Week 1 — Assignment 1: Neural Network Foundations & PyTorch

This folder contains `Week1.ipynb`, a beginner-friendly notebook covering the five assignment tasks from the Week 1 brief:

1. Explain neurons, weights, biases, epochs, batches, and learning rate.
2. Create, reshape, multiply, and index PyTorch tensors.
3. Train a simple model on synthetic regression data.
4. Plot training and validation loss and inspect predictions on test data.
5. Compare two learning rates.

## Run the notebook

Install the required packages if needed:

```bash
pip install torch matplotlib jupyter
```

Open `Week1.ipynb` in Jupyter Notebook, JupyterLab, or VS Code and run the cells from top to bottom.

The MNIST handwritten digit recognizer is maintained separately in `../Mini-project/`.
